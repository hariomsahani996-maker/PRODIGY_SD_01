Temperature Conversion Program

Task 01 – Prodigy InfoTech Internship

This project is a simple Temperature Conversion Program developed in Java as part of my Prodigy InfoTech internship.

Description

The program allows the user to enter a temperature value and select its original unit. It then converts the temperature into the other two units.

Supported Units

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- User-friendly console input
- Displays results with two decimal places

Technologies Used

- Java
- Scanner for user input
- Conditional statements
- Mathematical formulas

Example

If the user enters:

Original Unit: Celsius
Temperature: 25

The output will be:

Fahrenheit: 77.00 °F
Kelvin: 298.15 K

How to Run

1. Make sure Java is installed on your computer.
2. Compile the program:

javac TemperatureConversion.java

3. Run the program:

java TemperatureConversion
